# Weight provenance and DIMER hosting

- Upstream: `Prior-Labs/tabpfn_3` (TabPFN-3, Prior Labs; default classification checkpoint `tabpfn-v3-classifier-v3_default.ckpt`)
- Immutable revision: `24a16a89d245878b846555110985634aa2e656d7`
- Weight format: TabPFN checkpoint (`tabpfn-v3-classifier-v3_default.ckpt`, 212804803 bytes, SHA-256 `d0d865d54dfbc524f5703104be90620182dca7e5fb2c16de72e9959ea18f3988`; a pickle-based torch checkpoint; the pipeline no longer serves it)
- Served file: `tabpfn-v3-classifier-v3_default.safetensors` (212699804 bytes, SHA-256 `f1f5408aeeffdcdfaf4842f0eff072c67ff3fbbb2c29d46d14eb564190d0b7d2`, pinned as `CONVERTED_SHA256` / `CONVERTED_BYTES` in `pipeline.py`). `ensure_converted()` (called by `from_pretrained` and the notebook's weights stage) re-hashes the source checkpoint against `WEIGHTS_SHA256`, reads it once with `torch.load(map_location="cpu", weights_only=True)`, and writes the state dict (510 float32 tensors, contiguous CPU copies) with every other checkpoint field as sorted JSON header metadata (tabpfn's own `save_as_safetensors` layout) plus a `dimer_conversion` provenance field (`tabpfn-checkpoint-safetensors-v1`, source file, source SHA-256), under a sorted header (`safetensors_weights.py`, standard library only at import). Two independent conversions gave the same bytes. A file that does not match the pin is never moved into place; an existing file is reused only when its size and digest match. `TabPFNClassifier(model_path=<that file>)` then loads it through `tabpfn.checkpoint.Checkpoint`, which uses `safetensors.safe_open` and a strict `load_state_dict`: no `torch.load`.
- Equivalence (CPU, 2026-10-24; kept as `tests/test_safetensors_serving.py`, which runs when the checkpoint is staged): 510/510 tensors `torch.equal` with the same dtypes, `config` / `architecture_name` / `inference_config` equal; `predict_proba` on the 90 validation rows of the default synthetic sample identical to the `.ckpt` path (max abs diff 0.0), with `torch.load` patched to raise while the served model is built and used.
- Upstream weight license: `tabpfn-3-license-v1.0` — **non-commercial**: testing, evaluation and internal benchmarking only; production or externally offered service use requires Prior Labs' commercial licence. Not access-gated on the Hub (checked 2026-09-13 through the Hub API).
- Local snapshot: `weights/tabpfn-3-classifier/` with `dimer-base-manifest.json` (per-file bytes + SHA-256 for `LICENSE`, `README.md`, `config.json` and the checkpoint; `totalBytes` 212830007); the Git repository does not vendor the checkpoint (`weights/**/*.ckpt` is ignored; the three small files and the manifest are committable). The manifest was written from the Hub API (LFS SHA-256 and size for the checkpoint; the three small files fetched and hashed) — the checkpoint itself has **not** been staged locally, so `verify_snapshot` was exercised locally on the small files only; the notebook stages and re-hashes the checkpoint at run time. (2026-10-24: the checkpoint was staged locally, matched the manifest, and was used for the safetensors conversion and the equivalence check above.)
- `weights/model.ckpt` (untracked, 212,818,107 bytes) is a re-serialised copy of a TabPFN-3 checkpoint kept for the DIMER wizard upload; its digest matches no file of `Prior-Labs/tabpfn_3` at any revision, so it is **not** the pinned snapshot and the notebooks do not use it.
- Load-time check: `verify_snapshot()` in `src/tabpfn_classifier_pipeline/pipeline.py` re-hashes every manifest entry, refuses on any mismatch, and additionally requires the checkpoint digest to equal `WEIGHTS_SHA256`; `stage_missing_files(..., allow_download=True)` fetches only absent entries from the Hub at the immutable revision (never `main`).
- DIMER hosting: Model weights are hosted in the DIMER Model Repository for offline distribution, research, benchmarking, evaluation, and data science competitions under the TABPFN-3 Non-Commercial License (TABPFN-3 License v1.0). In accordance with Section 3.d (No Hosted Service), weights are distributed for offline and in-notebook execution, not as a live SaaS/API prediction endpoint without a commercial license from Prior Labs GmbH.
- Artifact bundles are format v2 (`DIMER_CONTRACT.md`): `save_artifact` copies the served safetensors file into the bundle as `model.safetensors` (bound to `CONVERTED_SHA256`) and no longer copies the source checkpoint, so `from_pretrained` needs the `.ckpt` only for the one-time conversion. Still on the old (`.ckpt`) contract: v1 bundles, including the pinned release asset `sample-artifact-synthetic-v1` (the notebook default until its staged v2 re-issue is published), read only with `torch.load(weights_only=True)` into a temporary safetensors file with a `DeprecationWarning`; the untracked `weights/model.ckpt` wizard copy; and the worker's base-model input `DIMER_TABPFN_MODEL_PATH` (a `.ckpt`, loaded by tabpfn under the `weights_only` guard).
- Loader trust boundary: `tabpfn.TabPFNClassifier(model_path=<verified safetensors file>)` on the pretrained path; the fitted artifact (`model.tabpfn_fit`) is TabPFN's own archive of JSON parameters plus serialised estimator state and is deserialised by `tabpfn.model_loading.load_fitted_tabpfn_model` — loading it executes trusted model state; no `trust_remote_code`, no remote code.
