# Weight provenance and DIMER hosting

- Upstream: `Prior-Labs/tabpfn_3` (TabPFN-3, Prior Labs; default classification checkpoint `tabpfn-v3-classifier-v3_default.ckpt`)
- Immutable revision: `24a16a89d245878b846555110985634aa2e656d7`
- Weight format: TabPFN checkpoint (`tabpfn-v3-classifier-v3_default.ckpt`, 212804803 bytes, SHA-256 `d0d865d54dfbc524f5703104be90620182dca7e5fb2c16de72e9959ea18f3988`; a torch checkpoint loaded by `tabpfn==8.1.0` through `model_path`)
- Upstream weight license: `tabpfn-3-license-v1.0` — **non-commercial**: testing, evaluation and internal benchmarking only; production or externally offered service use requires Prior Labs' commercial licence. Not access-gated on the Hub (checked 2026-09-13 through the Hub API).
- Local snapshot: `weights/tabpfn-3-classifier/` with `dimer-base-manifest.json` (per-file bytes + SHA-256 for `LICENSE`, `README.md`, `config.json` and the checkpoint; `totalBytes` 212830007); the Git repository does not vendor the checkpoint (`weights/**/*.ckpt` is ignored; the three small files and the manifest are committable). The manifest was written from the Hub API (LFS SHA-256 and size for the checkpoint; the three small files fetched and hashed) — the checkpoint itself has **not** been staged locally, so `verify_snapshot` was exercised locally on the small files only; the notebook stages and re-hashes the checkpoint at run time.
- `weights/model.ckpt` (untracked, 212,818,107 bytes) is a re-serialised copy of a TabPFN-3 checkpoint kept for the DIMER wizard upload; its digest matches no file of `Prior-Labs/tabpfn_3` at any revision, so it is **not** the pinned snapshot and the notebooks do not use it.
- Load-time check: `verify_snapshot()` in `src/tabpfn_classifier_pipeline/pipeline.py` re-hashes every manifest entry, refuses on any mismatch, and additionally requires the checkpoint digest to equal `WEIGHTS_SHA256`; `stage_missing_files(..., allow_download=True)` fetches only absent entries from the Hub at the immutable revision (never `main`).
- DIMER hosting: the non-commercial terms bar hosting the v3 weights as a production service; DIMER's live profile uses the v2 generation (Apache-derived licence, `Prior-Labs/TabPFN-v2-clf`) for that reason. The standalone notebooks pin v3 because that is the generation the pipeline's local weights and the DIMER worker default to; swapping the pin to v2 means changing `MODEL_ID` / `MODEL_REVISION` / `WEIGHTS_FILE` / `WEIGHTS_SHA256` in the module and regenerating the manifest and notebooks.
- Loader trust boundary: `tabpfn.TabPFNClassifier(model_path=<verified file>)`; the fitted artifact (`model.tabpfn_fit`) is TabPFN's own archive of JSON parameters plus serialised estimator state and is deserialised by `tabpfn.model_loading.load_fitted_tabpfn_model` — loading it executes trusted model state; no `trust_remote_code`, no remote code.
